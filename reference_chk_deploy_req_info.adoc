[role="lead"]
在 Hypervisor 環境中安裝部署管理公用程式之前、請先檢閱必要的組態資訊和選用的網路組態資訊、以準備成功部署。



[[required-configuration-information]]
== 必要的組態資訊

在您的部署規劃中、您應該先判斷必要的組態資訊、然後再安裝ONTAP Select 「整合部署」管理公用程式。

[cols="40,60"]
|===
| 必要資訊 | 說明 


| 部署虛擬機器（VM）的名稱 | 用於虛擬機器的識別碼。 


| Hypervisor 主機名稱 | 安裝 Deploy 實用程式的 VMware ESXi、Hyper-V 或 KVM Hypervisor 主機的識別碼。 


| 儲存設備位置名稱 | 用於儲存 VM 檔案的資料儲存區（ESXi）或儲存資源池（Hyper-V 或 KVM）的識別碼（大約需要 40GB）。 


| 虛擬機器的網路 | 部署虛擬機器所連接的網路的識別碼。 
|===


[[optional-network-configuration-information]]
== 選用的網路組態資訊

Deploy 虛擬機器預設使用 DHCP 設定。不過，如有需要，您可以手動設定虛擬機器的網路介面。

[cols="35,65"]
|===
| 網路資訊 | 說明 


| 主機名稱 | 主機的識別碼。 


| 主機IP位址 | 主機的靜態IPv4位址。 


| 子網路遮罩 | 子網路遮罩，基於虛擬機器所屬的網路。 


| 閘道 | 預設閘道或路由器。 


| 主要DNS伺服器 | 主網域名稱伺服器。 


| 次要DNS伺服器 | 次要網域名稱伺服器。 


| 搜尋網域 | 要使用的搜尋網域清單。 
|===
