您必須先正確設定Hypervisor網路、然後才能部署ONTAP Select 功能。



[[virtual-switch-options]]
== 虛擬交換器選項

您必須在ONTAP Select 每個支援外部網路和內部網路的各個支援主機上設定虛擬交換器（僅限多節點叢集）。在部署多節點叢集時、您應該測試內部叢集網路上的網路連線能力。


NOTE: 要了解有關如何在虛擬機管理程式主機上配置 vSwitch 以及高速介面功能的更多信息，請參閱 link:concept_nw_concepts_chars.html["深入探討網路"] 部分。



[[upgrade-to-vmxnet3-esxi-only]]
== 升級至 VMXNET3 （僅限 ESXi ）

從使用Deploy 2.10開始ONTAP Select 使用VMware 9.5、VMXNET3是VMware ESXi上新叢集部署所隨附的預設網路驅動程式。如果您將舊版 ONTAP Select 節點升級至 9.5 版或更新版本、則不會自動升級驅動程式。



[[cluster-mtu]]
== 叢集MTU

會使用分隔的內部網路來連接多節點叢集中的 ONTAP Select 節點。通常此網路的最大傳輸單元（MTU）大小為 9000。然而，在某些情況下，此 MTU 大小對於連接 ONTAP Select 節點的網路而言過大。為了容納較小的訊框，ONTAP Select 在內部網路上使用的 MTU 大小可介於 7500-9000 位元組的範圍內。

MTU大小會顯示在叢集建立頁面的叢集詳細資料區段中。此值由部署管理公用程式決定、如下所示：

. 初始預設值為9000。
. 當您新增HA配對的主機和網路時、MTU值會根據網路中VSwitch的組態而隨需降低。
. 叢集的最終叢集MTU值是在您新增所有HA配對並準備好建立叢集之後設定。



NOTE: 您可以根據網路設計、視需要手動設定叢集MTU值。



[[two-nic-host-with-standard-vswitch-esxi-only]]
== 含標準 vSwitch 的雙 NIC 主機（僅限 ESXi ）

為了在ONTAP Select 雙NIC組態中改善效能、您應該使用兩個連接埠群組來隔離內部和外部網路流量。本建議適用於下列特定組態：

* 多節點叢集ONTAP Select
* 兩個NIC（NIC 1和NIC 2）
* 標準vSwitch


在此環境中、您應該使用下列兩個連接埠群組來設定流量：

.連接埠群組1
* 內部網路（叢集、RSM、HA-IC流量）
* NIC 1為作用中狀態
* NIC 2處於待機狀態


.連接埠群組2.
* 外部網路（資料與管理流量）
* NIC 1為待機模式
* NIC 2處於作用中狀態


有關雙網卡部署的更多資訊，請參閱 link:concept_nw_concepts_chars.html["深入探討網路"] 章節。



[[four-nic-host-with-standard-vswitch-esxi-only]]
== 配備標準 vSwitch 的四 NIC 主機（僅限 ESXi ）

為了在ONTAP Select 四NIC組態中改善效能、您應該使用四個連接埠群組來隔離內部和外部網路流量。本建議適用於下列特定組態：

* 多節點叢集ONTAP Select
* 四個NIC（NIC 1、NIC 2、NIC 3和NIC 4）
* 標準vSwitch


在此環境中、您應該使用下列四個連接埠群組來設定流量：

.連接埠群組1
* 內部網路（叢集、RSM流量）
* NIC 1為作用中狀態
* NIC 2、NIC 3、NIC 4處於待命狀態


.連接埠群組2.
* 內部網路（叢集、HA-IC流量）
* NIC 3處於作用中狀態
* NIC 1、NIC 2、NIC 4處於待命狀態


.連接埠群組3.
* 外部網路（資料與管理流量）
* NIC 2為作用中狀態
* NIC 1、NIC 3、NIC 4處於待命狀態


.連接埠群組4.
* 外部網路（資料流量）
* NIC 4已啟用
* NIC 1、NIC 2、NIC 3處於待命狀態


有關四網卡部署的更多資訊，請參閱 link:concept_nw_concepts_chars.html["深入探討網路"] 章節。



[[network-traffic-requirements]]
== 網路流量需求

您必須確保防火牆設定正確，以允許網路流量在 ONTAP Select 部署環境中的各個參與者之間流動。

.參與者
有幾位參與者或實體在ONTAP Select 進行內部部署時、會交換網路流量。這些內容將會介紹、然後用於網路流量需求的摘要說明中。

* 部署
+
部署管理公用程式ONTAP Select

* vSphere（限 ESXi）
+
可以是 vSphere 伺服器或 ESXi 主機，取決於叢集部署中主機的代管方式

* Hypervisor 伺服器
+
ESXi Hypervisor 主機、Microsoft Hyper-V 主機或 Linux KVM 主機

* 節點ONTAP Select
+
ONTAP Select 節點

* 叢集ONTAP Select
+
ONTAP Select 叢集

* 管理 WS
+
本地管理工作站



.網路流量需求摘要
下表說明ONTAP Select 進行不完整部署的網路流量需求。

|===

| ICMP | ESXi、Hyper-V 或 KVM | 部署到每個 ONTAP Select 節點 | Ping 


| SSH（22） | ESXi、Hyper-V 或 KVM | 管理 WS 至每個 ONTAP Select 節點 | 系統管理
