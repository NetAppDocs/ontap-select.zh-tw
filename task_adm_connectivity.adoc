= 確認 ONTAP Select 節點之間的連線能力
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以測試ONTAP Select 內部叢集網路上兩個或多個節點之間的網路連線能力。您通常會在部署多節點叢集之前執行此測試、以偵測可能導致作業失敗的問題。

.開始之前
測試中包含的所有ONTAP Select 支援節點都必須設定並開啟電源。

.關於這項工作
每次開始測試時、會在背景中建立新的程序執行、並指派唯一的執行識別碼。一次只能啟用一次掃描。

測試有兩種模式可控制其運作：

* 快速
+
此模式執行基本的非中斷性測試。執行 PING 測試，以及網路最大傳輸單元（MTU）大小和 vSwitch 的測試。

* 擴充
+
此模式會對所有備援網路路徑執行更全面的測試。如果在作用中的 ONTAP Select 叢集上執行此模式，可能會影響叢集的效能。




NOTE: 建議您在建立多節點叢集之前、一律先執行快速測試。快速測試成功完成後、您可以根據正式作業需求、選擇性地執行延伸測試。

.步驟
. 使用系統管理員帳戶登入部署公用程式Web使用者介面。
. 選擇頁面頂端的 *Administration* 標籤，然後選擇 *Network Checker*。
. 選取 *Start New Run*，然後選取 HA 配對的主機和網路
+
您可以視需要新增及設定其他HA配對。

. 選取 *Start* 以開始網路連線測試。
