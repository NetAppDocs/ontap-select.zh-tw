= 保護 ONTAP Select 部署安全
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以視需要使用命令列介面變更 Deploy 虛擬機器系統管理員帳戶的密碼，以確保 ONTAP Select 部署是安全的。

.步驟
. 使用系統管理員帳戶登入部署公用程式CLI。
. 變更密碼：「密碼修改」
. 根據您的環境回應所有提示。
